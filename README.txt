Tab Tidy - install
1. Unzip this folder somewhere permanent (e.g. ~/Tools/tab-tidy).
2. In Chrome go to chrome://extensions and turn on "Developer mode" (top right).
3. Click "Load unpacked" and pick the tab-tidy folder.
4. Pin the extension (puzzle icon -> pin), then click it or press Option+Shift+T.

What it does
- Closes duplicate tabs across all windows (same URL, ignoring #anchors). Keeps the pinned/active copy.
- Groups the remaining tabs in each window by domain (docs.google.com, hub88.atlassian.net, ...).
- Domains with only one tab stay ungrouped. Pinned tabs and groups you named yourself are not touched.
- Settings are at the top of background.js.
